# About this folder

`savanna/` is the **Savanna static pages starter** from ALX (github.com/alx-africa/Savanna-static-pages), included
**unchanged**, as the organisers' Technical Guide asks ("savanna/: the starter, unchanged, plus your script tag").
It belongs to ALX and is **not** covered by this repository's MIT licence.

The only file Team Pixel added is `pages/signup.html`: the starter's own head, header and sidebar, with the
Inclusive Access sign-up component in `<main>` (two lines) and a listener that goes to the learner homepage when
sign-up is done. Savanna's own accessibility defects (for example the menu button) are the starter's, left as they are.

Open it at http://localhost:8080/savanna/pages/signup.html (docker compose, or `npm start` + `npm run demo`), or on the
deployed server at /site/savanna/pages/signup.html.
